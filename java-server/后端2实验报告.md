# 学生管理系统后端开发实验报告

## 一、项目概述

### 1.1 项目名称
基于Spring Boot的学生管理系统后端服务

### 1.2 项目简介
本项目是一个完整的学生管理系统后端服务，采用前后端分离架构，为前端提供RESTful API接口。系统实现了以下功能模块：

- 用户权限管理
- 学生信息管理
- 创新项目活动管理
- 课程管理
- 课表管理
- 成绩管理
- 奖惩管理
- 消费管理
- 考勤管理
- 请假管理
- 统计分析

### 1.3 技术栈
| 技术 | 版本 | 用途 |
|------|------|------|
| Java | 21 | 编程语言 |
| Spring Boot | 3.4.2 | 应用框架 |
| Spring Data JPA | - | 数据持久化 |
| Spring Security | - | 安全认证 |
| MySQL | 8.x | 关系型数据库 |
| JWT | 0.11.5 | Token认证 |
| Apache POI | 5.2.2 | Excel处理 |

## 二、功能模块详细设计

### 2.1 用户权限管理

#### 功能概述
实现用户登录认证、权限控制、用户信息管理等功能，支持管理员、教师、学生三种角色。

#### 实现功能
| 功能 | 描述 | 接口 |
|------|------|------|
| 用户登录 | 用户名密码验证，返回JWT Token | POST /api/auth/login |
| 查询用户 | 查询所有用户列表 | POST /api/user/findAll |
| 添加用户 | 新增用户账号 | POST /api/user/userSave |
| 修改用户 | 修改用户信息 | POST /api/user/userSave |

#### 权限设计
- **管理员(ADMIN)**：可查询所有用户，可添加/修改用户
- **教师(TEACHER)**：可查询所有用户
- **学生(STUDENT)**：无用户管理权限

#### 数据实体
- **User用户表**：存储用户账号、密码、用户类型、登录次数、最后登录时间等

## 五、个人总结

### 5.1 技术收获

1. **Spring Boot框架开发**
   - 掌握RESTful API设计规范
   - 熟练使用Spring Data JPA进行数据操作
   - 理解三层架构的设计思想

2. **安全认证机制**
   - 理解JWT无状态认证原理
   - 掌握Spring Security权限控制
   - 实现了RBAC角色权限模型

3. **数据库设计**
   - 掌握实体关联关系设计
   - 理解索引对性能的影响
   - 规范的表结构设计

### 5.2 开发经验

1. **功能模块化**：每个模块独立开发，接口清晰，便于维护
2. **权限精细化**：根据角色划分数据可见范围和操作权限
3. **流程规范化**：审批类功能采用状态机设计，流程清晰

### 5.3 心得体会

通过本次学生后端开发，我深刻体会到：

1. **接口设计的重要性**：良好的接口设计使前后端协作顺畅，统一的请求响应格式提高了开发效率

2. **权限控制的必要性**：学生管理系统涉及敏感数据，权限控制必须严谨，不同角色看到的数据范围要严格区分

3. **业务理解的关键性**：只有深入理解业务需求，才能设计出合理的接口和数据结构

4. **规范化的价值**：统一的代码风格、命名规范大大提高了代码可读性和团队协作效率

本次开发经历让我对后端开发有了更深入的理解，为今后的项目开发积累了宝贵经验。
