## 注意事项

1. **JPA 自动建表**: 项目使用 `ddl-auto: update` 模式，启动应用时 JPA 自动创建表结构和索引
2. **应用启动**: 测试需要 Spring Boot 应用运行（@SpringBootTest）
3. **端口冲突**: 确保 22224 端口未被占用
4. **MySQL连接**: 确保 MySQL 服务运行正常，数据库连接配置正确
5. **测试顺序**: 建议先运行 `testPerformanceReport()` 获取完整报告
6. **无需 SQL 文件**: 所有表结构和索引由 JPA 自动管理，不需要手动执行 SQL
