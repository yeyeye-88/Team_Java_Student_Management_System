## 一、数据库概述

### 1.1 设计目标
本数据库为学生管理系统的数据存储层，支持以下核心功能：
- 用户权限管理（3角色：管理员、学生、教师）
- 学生信息管理（基本信息、家庭成员）
- 课程与成绩管理（课程、课表、成绩）
- 考勤管理（考勤记录、考勤统计）
- 请假审批流程（请假申请、审批记录）
- 奖惩管理（荣誉记录、处分记录）
- 创新活动管理（创新项目、创新成果、活动参与）
- 统计分析（班级统计、成绩统计、考勤统计、请假统计）

### 1.2 设计规范
- **命名规范**: 表名使用下划线分隔（snake_case），字段名使用下划线分隔
- **字符集**: utf8mb4（支持中文和特殊字符）
- **存储引擎**: InnoDB（支持事务和外键）
- **主键策略**: 自增 INT（AUTO_INCREMENT）
- **外键约束**: 级联删除/更新（ON DELETE CASCADE / ON UPDATE CASCADE）

## 二、表结构设计

### 2.1 核心表（5个）

#### 1. person（人员表）
| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| person_id | INT | PRIMARY KEY, AUTO_INCREMENT | 人员ID |
| num | VARCHAR(20) | UNIQUE, NOT NULL | 人员编号（学号/工号） |
| name | VARCHAR(50) | NULL | 姓名 |
| type | VARCHAR(2) | NULL | 人员类型：0-管理员，1-学生，2-教师 |
| dept | VARCHAR(50) | NULL | 学院/部门 |
| card | VARCHAR(20) | NULL | 身份证号 |
| gender | VARCHAR(2) | NULL | 性别：1-男，2-女 |
| birthday | VARCHAR(10) | NULL | 出生日期 |
| email | VARCHAR(60) | NULL | 邮箱 |
| phone | VARCHAR(20) | NULL | 电话 |
| address | VARCHAR(20) | NULL | 地址 |
| introduce | VARCHAR(1000) | NULL | 个人简介 |
| photo | LONGBLOB | NULL | 照片 |

**索引**: 
- PRIMARY KEY (person_id)
- UNIQUE KEY uk_person_num (num)

---

#### 2. student（学生表）
| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| person_id | INT | PRIMARY KEY, FOREIGN KEY | 学生ID（关联person表） |
| major | VARCHAR(20) | NULL | 专业 |
| class_name | VARCHAR(50) | NULL | 班级 |

**索引**: 
- PRIMARY KEY (person_id)
- INDEX idx_class_name (class_name) ← 统计查询优化
- FOREIGN KEY (person_id) REFERENCES person(person_id) ON DELETE CASCADE

---

#### 3. user（用户表）
| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| person_id | INT | PRIMARY KEY, FOREIGN KEY | 用户ID（关联person表） |
| user_type_id | INT | NULL | 用户类型ID |

| password | VARCHAR(60) | NOT NULL | 密码（BCrypt加密） |

| last_login_time | VARCHAR(20) | NULL | 最后登录时间 |
| create_time | VARCHAR(20) | NULL | 创建时间 |

**索引**: 
- PRIMARY KEY (person_id)
- UNIQUE KEY uk_user_username (user_name)
- FOREIGN KEY (person_id) REFERENCES person(person_id) ON DELETE CASCADE

#### 4. menu（菜单表）

## 四、统计查询方法

### 4.1 班级学生数统计
```java
@Query("SELECT s.className, COUNT(s.personId) FROM Student s GROUP BY s.className")
List<Object[]> countStudentsByClass();
```

### 4.2 课程平均分统计
```java
@Query("SELECT s.course.courseId, AVG(s.mark) FROM Score s GROUP BY s.course.courseId")
List<Object[]> getAverageScoreByCourse();
```

### 4.3 课程考勤率统计
```java
@Query("SELECT a.course.courseId, " +
       "SUM(CASE WHEN a.state = 1 THEN 1 ELSE 0 END) * 100.0 / COUNT(a.attendanceId) " +
       "FROM Attendance a GROUP BY a.course.courseId")
List<Object[]> getAttendanceRateByCourse();
```

### 4.4 请假通过率统计
```java
@Query("SELECT SUM(CASE WHEN sl.state = 1 THEN 1 ELSE 0 END) * 100.0 / COUNT(sl.studentLeaveId) " +
       "FROM StudentLeave sl")
Double getLeavePassRate();
```
